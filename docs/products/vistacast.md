# VistaCast · 视界云遥

![VistaCast](/brand/vistacast-logo.svg)


> 角色 **视** · 组织 [VistaCast](https://github.com/VistaCast) · 官网 [vistacast.dev](https://vistacast.dev)

把已经装好的摄像头，变成门店、仓库和产线都能用的视觉能力。

VistaCast 是纯软件。它接现有的 ONVIF / RTSP 相机，也接按参考规格选的模组，在客户自己的机房里把画面整理成可以确认、可以交接、可以推给下游系统的事件。客流、安防和产线质检走同一套接入、规则和出站，按场景开通即可。

需要人远程上手时，搭配 [VistaRemote](./vistaremote)：VistaCast 负责看见并留下记录，VistaRemote 负责连上那台机器操作。

## 一套平台，三条场景

### 把门店的人流看清楚

过线客流和时段分布，直接从现有摄像头出来。连锁和单店能看到今天来了多少人、高峰在什么时候，用来排班、评估活动和调整门店节奏。

### 把仓库和园区的异常交得出去

区域入侵、夜间时段、摄像头离线，都变成可以确认、可以标误报的告警。交接班看的是事件，原画面留在客户侧。

### 让工位质检留得下证据

电子与 3C 产线上，VistaCast 也可以做工位光学检查：回流焊之后看焊点外观，波峰焊之后看连锡和少锡，插件看有无、极性和歪斜，包装看数量、封箱和条码。每一次判定都带着图片，复判之后能汇总直通率和缺陷分布。

结果通过 Webhook / MQTT 送给客户自己的产线系统。贴片坐标可以生成检查区域，配方不用在屏幕上逐个画框。判定跑在工位旁边，用确定的视觉算法，画面不出客户网络。

这一条看的是表面能看见的焊点和外观，适合标准高速检测设备覆盖不到的工位，也适合还在用人工目检、希望先把记录留下来的小线。

## 每个场景都带着这些能力

| 能力 | 客户得到什么 |
|------|----------------|
| **沿用现有相机** | ONVIF 发现、RTSP 取流，门店、仓库、工位都能接 |
| **按场地管理** | 门店、仓库、工位各自成站，权限跟着站点走 |
| **规则可配** | 画区域、设时段和阈值，重复告警会合并 |
| **事件交得出去** | 客流是计数，安防是告警，质检是带图的通过或不良 |
| **私有化部署** | 画面和原图留在客户环境 |
| **企业账号** | 用 LuminaryWorks 统一登录，也可以换成客户自己的身份系统 |

## 和生态怎么配合

```text
VistaCast
  ├─► 门店与仓储 — 客流、入侵、离线
  ├─► 产线工位 — 焊点、插件、包装，图片留在客户侧
  ├─► DataLuminary — 客流、告警、直通率
  ├─► SyncroBrain — 设备与工艺上下文
  ├─► VistaRemote — 有人需要远程查看现场
  └─► DoerFlow — 把事件或复判变成可结算的任务
```

画面和原图留在你们的环境里。相机走 ONVIF / RTSP，结果用 Webhook 或 MQTT 交给你们已经在用的系统。员工可以用 LuminaryWorks 账号，也可以用公司自己的身份系统。
